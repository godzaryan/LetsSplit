# Contributing to LetsSplit

Thank you for your interest in contributing to LetsSplit! To ensure a smooth process and high-quality codebase, we follow a standard Fork & Pull Request workflow. 

## How to Contribute

1. **Fork the Repository**: Click the "Fork" button at the top right of this page to create a copy of the repository in your own account.
2. **Clone your Fork**: `git clone https://github.com/your-username/LetsSplit.git`
3. **Set Up the Environment**: 
   - Run `npm install` to install dependencies.
   - Copy `.env.example` to `.env` or `.env.local` and fill in your Supabase credentials.
4. **Create a Branch**: Create a new branch for your feature or bug fix: `git checkout -b feature/your-feature-name`
5. **Make your Changes**: Write your code. Make sure to test your changes locally.
6. **Commit and Push**:
   - `git commit -m "Add some feature"`
   - `git push origin feature/your-feature-name`
7. **Submit a Pull Request**: Go to the original repository and click "New Pull Request". Please fill out the provided Pull Request template.

## Review Process

- **Only the Owner Approves**: All pull requests must be reviewed and approved by the repository owner before they can be merged into the main branch.
- **Keep it Clean**: Ensure your code follows the existing style and is free of sensitive information (do not commit `.env` files, API keys, or personal notes).

We appreciate your contributions!
